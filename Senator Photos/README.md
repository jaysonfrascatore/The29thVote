# Senator Photos

Photos for the senator tooltips, map, prediction cards and Previous Updates.
The live site doesn't use this folder yet, so adding photos here won't change anything until the photo feature is switched on.

**How to name them:** last name, a dash, the state, `.png`. Spaces become dashes and accents are dropped. Capital letters matter.
Transparent background, head and shoulders, about 320×320 pixels.
